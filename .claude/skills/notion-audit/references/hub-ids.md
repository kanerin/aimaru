## テストの実行方法

| 対象 | コマンド | 備考 |
|---|---|---|
| Cloud Functions | `cd functions && npm ci && npm test` | Node 22。`node --test` を使う |
| Cloud Functions の型 | `cd functions && npm run typecheck` | テスト込みで型を通す |
| Flutter 単体・ウィジェット | `flutter test` | Flutter SDK が無い環境では実行できない |
| Flutter 結合 | `flutter test integration_test/app_test.dart -d <device>` | 実機・エミュレータが必要。棚卸しでは走らせない |

## 既知の未解決事項

棚卸しで毎回「新発見」として報告しないよう、既に把握している問題を控えておく。
解決したらこの節から消す。

- `sendReminders` が `collectionGroup` の全件走査でスケールしない（REQ-028 / FEAT-048）
- 予定単位の `reminded` フラグのため、メンバーの片方だけが通知窓に入ると
  もう片方の通知が失われる（TC-059）
- Firestore / Storage のセキュリティルールに自動テストが無い。README にある
  `rules_test/` は実在しない（REQ-027）
- Gemini API キーがビルド成果物に埋め込まれる（REQ-026 / FEAT-046）
- CI がまだ GitHub の必須チェックになっていない（管理者権限が必要）
